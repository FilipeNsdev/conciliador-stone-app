# Conciliador Stone · Bar do Sabão

Programa para Windows que confere as vendas de cartão e Pix das maquininhas Stone contra o extrato.

## Instalar ou atualizar

Abra o **PowerShell** e cole:

```powershell
irm https://raw.githubusercontent.com/FilipeNsdev/conciliador-stone-app/main/install.ps1 | iex
```

- Não precisa de administrador.
- Cria atalhos na área de trabalho e no menu Iniciar.
- O programa procura atualização sozinho sempre que abre.

## Privacidade

Os documentos são lidos só no computador. Nada é enviado para a internet; o programa só consulta este repositório para saber se há versão nova.

## Requisitos

Windows 10 ou 11 com o Microsoft Edge WebView2 (já vem no Windows 11). Se faltar, o programa abre a página de download da Microsoft.
